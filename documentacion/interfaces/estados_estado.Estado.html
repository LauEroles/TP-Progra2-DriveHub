Interface Estado

Interface que define el contrato para los diferentes estados de un vehículo. Implementa el patrón State para gestionar las transiciones de estado de los vehículos.

interface Estado {
    alquilar(vehiculo): void;
    devolver(vehiculo): void;
    enviarMantenimiento(vehiculo): void;
    estaEnAlquiler(): boolean;
    finalizarMantenimiento(vehiculo): void;
    limpiar(vehiculo): void;
}

estaEnAlquiler

  • estaEnAlquiler(): boolean

  • Verifica si el vehículo está en estado de alquiler. Este método es utilizado por la clase GestorEstadisticas para generar reportes de ocupación de flota. Nota: Se agregó este método de consulta intentando no romper el patrón State, permitiendo conocer el estado y realizar el conteo de los vehiculos en alquiler, sin exponer la implementación concreta del estado actual.

    Returns boolean
